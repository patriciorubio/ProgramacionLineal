01 — metodología

Los 5 pasos de la formulación

Antes de abrir Python, necesitas construir el modelo matemático. Este proceso es el 80% del trabajo real.

Problema real lenguaje natural, ambigüedad
→
Modelo matemático variables, FO, restricciones
→
Código PuLP, SciPy, GAMS...
paso 1Identifica las variables de decisión

Pregunta: ¿qué puedo controlar?
Son los números que tú decides. Se nombran con letras (x₁, x₂, y, z…) y siempre tienen unidades.

x₁ = unidades de producto A fabricadas por día
x₂ = unidades de producto B fabricadas por día
paso 2Define la función objetivo

Pregunta: ¿qué quiero optimizar?
Una sola expresión matemática que resume el objetivo. Siempre es MAX o MIN.

MAX Z = 5x₁ + 8x₂
paso 3Escribe las restricciones

Pregunta: ¿qué me impide hacer lo que quiero?
Cada recurso limitado, obligación o condición es una restricción.

2x₁ + 4x₂ ≤ 100 (horas máquina)
3x₁ + 2x₂ ≤ 90 (kg de material)
x₁, x₂ ≥ 0 (no negatividad)
paso 4Verifica el modelo

Antes de programar: ¿tiene sentido? Prueba valores extremos manualmente.

  • ✓
    Cada restricción tiene unidades consistentes (no mezcles kg con horas)
  • ✓
    La FO tiene las mismas unidades en todos sus términos
  • ✓
    Hay al menos una solución factible (el problema no es imposible)
  • ✓
    El problema está acotado (el óptimo no es infinito)
  • ✓
    Las variables de no negatividad están incluidas
paso 5Traduce a código

Con el modelo validado, la traducción a Python es casi mecánica. Verás que es una copia directa del modelo matemático.

02 — función objetivo

Construir la FO paso a paso

La función objetivo es la brújula de tu modelo. Todo lo demás sirve para llegar al mejor valor de esta expresión.

Anatomía de una función objetivo
MAX Z = c₁·x₁ + c₂·x₂ + ... + cₙ·xₙ
SímboloNombre¿Qué representa?
ZVariable de valorLa ganancia / costo total que buscamos optimizar
cᵢCoeficiente objetivoLo que aporta/cuesta una unidad de xᵢ (ganancia por unidad, costo unitario…)
xᵢVariable de decisiónLa cantidad que decidimos de cada producto/acción
¿MAX o MIN? — regla práctica
Usas MAX cuando...Usas MIN cuando...
Quieres maximizar ganancia, utilidad, ingresos, producción, eficienciaQuieres minimizar costos, tiempo, distancia, desperdicios, penalizaciones
Ejemplo: "¿Cuánto producir para ganar más?"Ejemplo: "¿Qué ruta usar para llegar más rápido?"
💡 MIN Z = f(x) es equivalente a MAX −Z = −f(x). Puedes convertir uno en el otro.
Errores comunes al formular la FO
ErrorIncorrectoCorrecto
Mezclar unidadesMAX 5x₁ + 2x₂ (x₁ en kg, x₂ en litros)Convertir todo a la misma base monetaria o física
Doble conteoIncluir el mismo ingreso dos vecesCada elemento aparece una sola vez en la FO
Olvidar términosMAX 5x₁ (ignoras x₂ que también genera ganancia)Incluir todas las variables que afectan el objetivo
FO no lineal confundida con linealMAX x₁·x₂ (producto de variables)Linealizar o usar programación no lineal

03 — restricciones

Tipos de restricciones

Las restricciones son la realidad del problema. Cada límite físico, económico o legal se convierte en una desigualdad o igualdad matemática.

Restricciones de recurso (≤)

"No puedo usar más de lo que tengo disponible." El tipo más frecuente.

// Recurso: 40 horas de mano de obra disponibles
2x₁ + 3x₂ ≤ 40

// Patrón: (uso por unidad) × (cantidad) ≤ disponibilidad
horas máquina presupuesto capacidad de almacén materia prima espacio físico
Restricciones de demanda mínima (≥)

"Debo producir al menos cierta cantidad." Compromisos, contratos, mínimos de mercado.

// Debo cumplir un pedido mínimo de 10 unidades de A
x₁ ≥ 10

// La mezcla de producto A debe ser al menos 30% del total
x₁ ≥ 0.30 (x₁ + x₂) → 0.7x₁ − 0.3x₂ ≥ 0
Restricciones de igualdad (=)

"Se debe cumplir exactamente." Balances, mezclas específicas, flujos de conservación.

// Balance de flujo en un nodo de red
flujo_entrada = flujo_salida

// Todo el presupuesto debe invertirse
x₁ + x₂ + x₃ = 100000
Restricciones de no negatividad

Casi siempre obligatorias. No puedes producir cantidades negativas.

x₁, x₂, ..., xₙ ≥ 0
Excepción: en finanzas, variables pueden ser negativas (posición corta). En ese caso omite esta restricción para esa variable.
Tabla de traducción: lenguaje natural → matemáticas
FraseTipoExpresión
"no más de", "como máximo", "disponible"≤uso ≤ capacidad
"al menos", "mínimo", "no menos de"≥producción ≥ mínimo
"exactamente", "debe ser", "igual a"=cantidad = valor fijo
"entre A y B"dobleA ≤ x ≤ B
"si se produce X, entonces Y"lógicaprogramación entera (variables binarias)

04 — ejemplos resueltos

Del enunciado al modelo

Tres ejemplos completos con el proceso de formulación detallado.

Ejemplo 1 — Producción de muebles

Enunciado: Una fábrica produce mesas ($120 ganancia) y sillas ($80 ganancia). Cada mesa requiere 4 horas de carpintería y 2 de pintura. Cada silla requiere 2 horas de carpintería y 3 de pintura. Disponible: 240 h carpintería, 210 h pintura. ¿Cuánto producir para maximizar ganancia?

Paso 1 — Variables:

x₁ = mesas/semana    x₂ = sillas/semana

Paso 2 — Función objetivo:

MAX Z = 120x₁ + 80x₂

Paso 3 — Restricciones:

4x₁ + 2x₂ ≤ 240 (carpintería)
2x₁ + 3x₂ ≤ 210 (pintura)
x₁, x₂ ≥ 0
Ejemplo 2 — Dieta mínima (minimización)

Enunciado: Un alimento A cuesta $2/kg y tiene 3g proteína + 1g grasa por kg. El alimento B cuesta $3/kg y tiene 1g proteína + 2g grasa. Se requiere: ≥12g proteína y ≥8g grasa. Minimizar costo.

Variables:

x₁ = kg de alimento A    x₂ = kg de alimento B

Función objetivo:

MIN Z = 2x₁ + 3x₂

Restricciones:

3x₁ + x₂ ≥ 12 (proteína mínima)
x₁ + 2x₂ ≥ 8 (grasa mínima)
x₁, x₂ ≥ 0
Ejemplo 3 — Mezcla de inversión

Enunciado: Tienes $100,000 para invertir en bonos (6% rendimiento, riesgo bajo) y acciones (12% rendimiento, riesgo alto). Máximo 60% en acciones. Mínimo 20% en bonos. Maximizar rendimiento.

Variables:

x₁ = $ en bonos    x₂ = $ en acciones

Función objetivo:

MAX Z = 0.06x₁ + 0.12x₂

Restricciones:

x₁ + x₂ = 100,000 (invertir todo)
x₂ ≤ 60,000 (máx 60% acciones)
x₁ ≥ 20,000 (mín 20% bonos)
x₁, x₂ ≥ 0

05 — python / pulp

De la matemática al código

Con PuLP, el modelo matemático se traduce línea a línea. La correspondencia es casi exacta.

Instalación
# En terminal: pip install pulp
Estructura general de un modelo PuLP
from pulp import * # 1. Crear el problema prob = LpProblem("nombre_problema", LpMaximize) # o LpMinimize # 2. Variables de decisión x1 = LpVariable("x1", lowBound=0) # x1 ≥ 0 x2 = LpVariable("x2", lowBound=0) # x2 ≥ 0 # 3. Función objetivo prob += 5*x1 + 8*x2, "Funcion_Objetivo" # 4. Restricciones prob += 2*x1 + 4*x2 <= 100, "Recurso_A" prob += 3*x1 + 2*x2 <= 90, "Recurso_B" # 5. Resolver prob.solve() # 6. Resultados print(f"Estado: {LpStatus[prob.status]}") print(f"x1 = {x1.value()}") print(f"x2 = {x2.value()}") print(f"Z = {value(prob.objective)}")
Ejemplo completo — Fábrica de muebles (Ej. 1)
from pulp import * # Modelo: MAX Z = 120·x1 + 80·x2 # s.a. 4x1 + 2x2 ≤ 240 (carpintería) # 2x1 + 3x2 ≤ 210 (pintura) # x1, x2 ≥ 0 prob = LpProblem("Fabrica_Muebles", LpMaximize) # Variables x1 = LpVariable("mesas", lowBound=0) x2 = LpVariable("sillas", lowBound=0) # Función objetivo prob += 120*x1 + 80*x2, "Ganancia_Total" # Restricciones prob += 4*x1 + 2*x2 <= 240, "Carpinteria" prob += 2*x1 + 3*x2 <= 210, "Pintura" # Resolver prob.solve(PULP_CBC_CMD(msg=0)) # Resultados print("--- SOLUCIÓN ÓPTIMA ---") print(f"Mesas (x1): {x1.value():.1f} unidades") print(f"Sillas (x2): {x2.value():.1f} unidades") print(f"Ganancia Z : ${value(prob.objective):,.2f}") # Análisis de holgura print("\n--- HOLGURA (recursos sin usar) ---") for name, c in prob.constraints.items(): print(f"{name}: holgura = {-c.slack:.1f} horas") # Output esperado: # --- SOLUCIÓN ÓPTIMA --- # Mesas (x1): 45.0 unidades # Sillas (x2): 30.0 unidades # Ganancia Z : $7,800.00
Tipos de variables en PuLP
# Variable continua (por defecto) x = LpVariable("x", lowBound=0) # Variable entera (no fraccionada) x = LpVariable("x", lowBound=0, cat="Integer") # Variable binaria (0 o 1) — para decisiones Sí/No y = LpVariable("y", cat="Binary") # Variable con límites superior e inferior x = LpVariable("x", lowBound=5, upBound=50) # 5 ≤ x ≤ 50
Muchas variables — usando listas y lpSum
from pulp import * # Cuando tienes n productos, usa diccionarios productos = ["A", "B", "C", "D"] ganancia = {"A": 5, "B": 8, "C": 3, "D": 6} uso_maq = {"A": 2, "B": 4, "C": 1, "D": 3} prob = LpProblem("Multi_Producto", LpMaximize) # Variables como diccionario x = LpVariable.dicts("x", productos, lowBound=0) # FO con lpSum (equivale a sumatoria Σ) prob += lpSum([ganancia[p] * x[p] for p in productos]) # Restricción de máquina prob += lpSum([uso_maq[p] * x[p] for p in productos]) <= 100 prob.solve(PULP_CBC_CMD(msg=0)) for p in productos: print(f"x[{p}] = {x[p].value()}")
